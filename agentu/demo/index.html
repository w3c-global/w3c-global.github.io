What does verification prove?

Each record contains the previous record’s SHA-256 hash. Verification checks the sequence, links and contents for consistency. This demo does not use an external signature or an immutable store: an administrator with database access could rewrite the entire chain. The export can be checked independently using the verifier supplied with the project.
