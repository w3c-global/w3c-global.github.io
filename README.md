# W3C / World3 Corporation

GitHub Pages repository for World3 Corporation and its group company, Agentu.

## Sites

- [W3C / World3 Corporation](https://www.w3ccorp.com/) is published from the repository root.
- [Agentu](https://www.w3ccorp.com/agentu/) is published from [`agentu/`](agentu/).
- [Agentu brand assets](https://www.w3ccorp.com/agentu/brand/) are published from [`agentu/brand/`](agentu/brand/).

Both sites are static HTML, CSS and vanilla JavaScript. There is no build step.

## Local preview

Serve the repository root with any static web server, for example:

```bash
python -m http.server 4321
```

Then open <http://localhost:4321/> for World3 or <http://localhost:4321/agentu/> for Agentu.

## Deployment

GitHub Pages publishes the `main` branch from `/ (root)`. The repository-level `.nojekyll` file keeps every static asset available without Jekyll processing.

The pre-consolidation corporate and Agentu site histories were retained when the sites were brought together here.
